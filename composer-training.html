06 / MoE PRECISION

The expert routing nightmare.

PROBLEM
Float drift → wrong expert
a+b+c ≠ c+b+a in fp. 5th decimal drift → router picks expert 7 instead of 9. Trainer updates an expert that inference never used. Signal destroyed.
FIX · ROUTER REPLAY
Inference ships expert IDs as ints
For each token: {layer, [exp_ids]}. Trainer reuses them verbatim — no recomputation, no mismatch.
FIX · KERNEL MATCH
Match quant / op-order
Accept ~few % perf loss → kill 90% of numeric drift. Production trains in FP4.

10 / TAKEAWAYS

What it all means.

six things to remember
▸ 01
Specialize, don't generalize.
Model is a finite disk. Give every bit to your one job.
▸ 02
Your product is the RL env.
No toy gyms. Clone production, run 100K VMs on demand.
▸ 03
Async or die.
Sync = half the GPUs idle. Accept staleness, gain throughput.
▸ 04
Numerics is everything.
Router Replay + kernel match. Without it MoE-RL diverges.
▸ 05
Split train ≠ infer.
Train central, infer global & cheap. 1TB sync via delta.
▸ 06
Software 3.0 = writing rewards.
1.0 wrote code · 2.0 fed data · 3.0 designs eval rules.
