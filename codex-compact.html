实验数据出处 Kangwook Lee 用 prompt injection 套出了服务端 compaction prompt,发现与开源版几乎一致。 但同一长程任务下 Local 28 vs Remote 94 — 差距不在提示词,而在服务端的整条 pipeline(压缩器模型 + 加密前后处理 + 解密时的 context assembly)。

4黑盒里到底藏了什么 — 点击 tile 展开
